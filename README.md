# AgileIQ

AI-powered Agile Project Management Platform.

## Overview

AgileIQ is an intelligent Agile project management platform designed to automate and optimize:

- Ticket classification
- Smart prioritization
- Bug analysis
- Predictive project analytics
- Agile workflow management

The platform is built entirely with open-source technologies.

---

## Tech Stack

### Backend
- Python 3.11
- FastAPI
- SQLAlchemy
- PostgreSQL

### AI / Machine Learning
- spaCy
- sentence-transformers
- scikit-learn

### Frontend
- React

### DevOps
- Docker
- Prometheus
- Grafana
- GitHub Actions
